# Dataset

The project uses a publicly available Heart Disease Dataset containing clinical information collected from patients.

## Input Features

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Serum Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise Induced Angina
- ST Depression (Oldpeak)
- Slope of ST Segment
- Number of Major Vessels
- Thalassemia

These features are used by the machine learning model to predict the likelihood of heart disease.
