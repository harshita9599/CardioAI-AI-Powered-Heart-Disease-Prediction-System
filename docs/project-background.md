# Project Background

CardioAI was developed as an implementation of a university research project on Artificial Intelligence for Cardiac Health Diagnosis.

The original research focused on understanding how Artificial Intelligence, Machine Learning, and Deep Learning techniques can assist healthcare professionals in the early detection of cardiovascular diseases. It explored different datasets, machine learning algorithms, deep learning approaches, benefits, limitations, and real-world healthcare applications.

Based on the concepts studied during the research phase, this project was later implemented as a Flask-based web application that predicts heart disease risk using machine learning models trained on clinical patient data.

The objective of this implementation is to demonstrate how research concepts can be transformed into a practical healthcare application with an interactive user interface.
