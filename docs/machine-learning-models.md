# Machine Learning Models

Several supervised machine learning algorithms were studied and evaluated during the development of this project.

## Logistic Regression

Used for binary classification to determine whether a patient is likely to have heart disease.

## Decision Tree

Creates decision rules based on patient clinical features to classify disease risk.

## Random Forest

Combines multiple decision trees to improve prediction accuracy and reduce overfitting.

## Support Vector Machine (SVM)

Separates patients into different classes by identifying the optimal decision boundary.

The final prediction model is selected based on its overall performance after training and evaluation.
